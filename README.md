**1.The Anaconda/Miniconda program was installed to facilitate the easy installation of bioinformatics tools, specifically MEGAHIT.**
Genome assembly was conducted using MEGAHIT, a de novo assembler that is optimized for large metagenomic datasets. MEGAHIT was installed via Bioconda using Anaconda/Miniconda.
For each of the six samples, assemblies were generated by running MEGAHIT on the paired-end FASTQ files. The general command format used was:
`megahit -1 sim_tX_1.fq -2 sim_tX_2.fq -o tX_out`
Each execution produced an output directory (t1_out through t6_out), which contained the assembled contigs in a file named:
`final.contigs.fa`
These assembled FASTA files were subsequently used for downstream alignment and phylogenetic analysis.

**2. In R program, the following code was executed:**
All analyses were conducted in R using the Biostrings and DECIPHER packages. Assembled contigs from each MEGAHIT output folder were imported with the `readDNAStringSet()` function. These contigs were then combined into a single `DNAStringSet` object.

**Biostrings allows R to read DNA sequences from FASTA files, while DECIPHER performs alignment and builds phylogenetic trees. To install these packages:**
- BiocManager::install("Biostrings")
- BiocManager::install("DECIPHER")

**Load required libraries, so we can use them.**
- library(Biostrings)
- library(DECIPHER)

**Read in megahit assembly results for each sample.**
- `allcontigs <- c()`  Creates an empty object allcontigs, loops from sample 1 to 6, reads each sample’s `final.contigs.fa`,  and appends all contigs into one big list.
- `allcontigs <- c()`
- `for(i in 1:6){`
- `contigs <- readDNAStringSet(paste0('C:/Users/sabye/Downloads/t', i, '_out/final.contigs.fa'))`

**This loop outputs a list, so we flatten the list. The loop creates a list of DNAStringSets.**
`allcontigs <- do.call(c, allcontigs)`

**There are some small fragments of genomes in the assembly**

To eliminate small assembly fragments, only contigs longer than 5,000 bp were retained, as the target viral genome is approximately 18 kbp in length. The filtered sequences were assigned numeric identifiers.
- To align the biggest parts, use the command: 
- `toalign <- allcontigs[which(nchar(allcontigs) > 5000)]`
- `names(toalign) <- 1:length(toalign)`
-	`names(toalign)` gives each sequence a simple numeric name.

**We command `alignment <- AlignSeqs(toalign)`**

Multiple sequence alignment was performed using the `AlignSeqs()` function from DECIPHER. This function computes k‑mer distances, clusters sequences based on their similarity, and carries out a progressive alignment with refinement. The resulting alignment was exported as an HTML file using `BrowseSeqs()`.

**View the alignment.**
-	 We command `BrowseSeqs(alignment, htmlFile = 'final_project.html')`
-	This will create an HTML file showing the alignment visually.
  
**Build a Phylogenetic Tree**

A phylogenetic tree was constructed from the aligned sequences using the Treeline() function from the DECIPHER package, `tree <- Treeline(alignment, method = 'ML', showPlot = T)`, employing the maximum likelihood (ML) method. Several nucleotide substitution models were evaluated, including JC69, K80, HKY85, T92, TN93, SYM, and GTR. The selection of the best model was based on AICc and BIC scores.

The T92 model was identified as the best fit. The estimated parameters for this model were as follows:

- Frequency of A = Frequency of T = 0.293
- Frequency of C = Frequency of G = 0.207
- Transition rate = 0.973
- Transversion rate = 1

### Explanation
The maximum likelihood phylogenetic tree reveals distinct clustering patterns among the six assembled viral genomes. Samples 2 and 3 form the closest pair, as indicated by their short branch lengths and shared internal node. A second closely related pair is identified between samples 1 and 4, which also share a recent common ancestor.
In addition to these primary clusters, sample 5 branches nearest to the 2–3 group, suggesting it is more distantly related, yet still part of the same broader lineage. Sample 6 is most closely associated with the 1–4 cluster, representing the next-closest relationship within that lineage.
The phylogeny consists of six distinct terminal nodes, each representing a unique assembled genome. This data suggests that the six samples likely originated from six different individuals, as no samples share identical sequences, and no terminal branches collapse into a single tip, supporting this conclusion.
